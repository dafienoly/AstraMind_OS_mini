# ADR-0006：周期策略血缘与核心组合策略分离

H20 与 H60 使用独立的 `Strategy Lineage`、准确模型版本、校准器、证据和晋级判断；
用户不必为两个周期选择同一因子包或同一模型。组合层用唯一 `CorePolicyVersion`
绑定两个准确周期版本、固定各 50% 的虚拟预算、O0、费用和风险约束。

季度更新先分别判断 H20/H60：新版本通过则采用，新版本失败但旧版本仍有效则保留，
两者都无效则该周期预算留现金。随后系统只生成一个确定的 CorePolicy 供用户原子确认，
不展示或持久化所有 H20 × H60 交叉组合。

这一选择保留不同周期的真实差异，同时阻止模型候选、周期版本和组合策略形成复杂度
爆炸。历史收益属于各 lineage 的证据版本；当前准确模型不能回填历史。模型晋级也不
自动授权 CorePolicy、Shadow、Paper、Live 或券商执行。
