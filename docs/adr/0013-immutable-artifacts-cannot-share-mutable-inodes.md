# ADR-0013：不可变制品不得与可变工作文件共享 inode

内容寻址的数据集、`DataSnapshot`、模型制品和研究证据一经发布，物理内容必须保持
不可变。发布器不得使用硬链接把仍会被增量更新、覆盖或压缩重写的工作文件放入不可变
目录；同一设备上的 `os.link` 也不例外。

发布必须采用以下任一安全方式：

- 把已冻结且之后不再写入的临时文件原子移动到内容寻址目录；
- 复制到临时发布目录，复核字节哈希、行数、主键、日期范围与清单后原子重命名；
- 使用能够保证写后不可变且按内容身份读取的对象存储语义。

发布前后都必须校验制品字节哈希。清单还要记录可复算的行数、主键范围和市场日期范围；
任一不一致都阻断当前指针切换。启动恢复和日度运行不得通过修改已发布文件来“补齐”
旧版本，只能发布新版本并显式重组新 `DataSnapshot`。

已经发现或怀疑与工作文件共享 inode 的历史制品不得继续作为正式训练、封存回放或
晋级证据。恢复流程必须保留旧身份和审计记录，重新从已验证来源发布新版本，再原子
切换当前指针；不得静默改写旧清单或哈希。

该决定只约束本地数据与模型制品的物理发布方式，不授权提供方联网、MiniQMT 账户、
Paper、Live 或券商动作。
