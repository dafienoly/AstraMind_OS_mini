# ADR-0010：先冻结粗筛候选，再按需拉取日内数据

全市场长期保存完整 Tick 会扩大存储、回填和研究复杂度，而 5 万元短线分仓最终通常只
持有一至两只股票。MiniQMT 可以按需提供分钟/Tick 数据，因此短线研究采用两阶段漏斗：

1. 先用一个不可变日频 `FeatureSnapshot` 对全市场粗筛，并发布冻结候选、排序、证据
   截止时间和策略版本的 `CoarseScreeningBatch`；
2. Data 上下文据此生成提供方中立的候选级日内请求，对完整冻结候选集使用相同字段、
   频率、回看窗口和质量门拉取数据；策略代码不得直接调用 MiniQMT；
3. 原始响应、规范观察、覆盖、缺口、会话、检索时间和内容哈希分别留存，只有封存后的
   日内数据集可以进入研究快照；当前会话投影不能成为模型或回测输入；
4. 首版日内层只输出“通过 / 风险否决 / 数据不足”三态，不重新排序、学习第二套分数
   或替换缺数据候选；
5. 历史评价必须先在每个历史决策日重放当时的日频粗筛，再获取该日冻结候选的截止前
   日内数据；人工看图后选择的关注标的只作诊断，不计入策略证据；
6. 两阶段候选必须与日频父级使用相同决策日、成本、可交易约束和组合规则做端到端
   A/B。日内验证器没有稳定成本后增量时，日频父级保持有效。

该选择允许对粗筛后的条件候选集做有效研究，但不能据此宣称拥有全市场分钟/Tick 因子
证据。任何可学习的日内重排模型、周度核心 `MKT1` 因子包或盘中交易策略都需要独立
需求、准确身份和样本外证据。
