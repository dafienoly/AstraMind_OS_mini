- 状态：草案；研究方向已确认，实施未授权

- 目标阶段：阶段 5D

- 追踪：见[需求索引唯一追踪表](./README.md#唯一追踪表)

## 目标

检验同一决策时点其他股票的特征和状态，是否能在表格模型与只看自身特征的模型之外，
稳定改善 A 股 H20/H60 截面排序。跨股票信息共享是待验证假设，不是组合权重或订单。

## 前置条件

- REQ-2026-0007 v2.0.0 的点时面板、Ridge/LightGBM 基线和核心统计证据已经稳定；
- 另行冻结特征白名单、截面股票池、掩码、随机种子和 CPU/GPU 资源预算；
- 新工作包证明 `PredictionBatch → OptimizationProblem` 边界不变。

## 独立消融阶梯

| 层级 | 候选 | 必须回答的问题 |
| --- | --- | --- |
| A0 | Ridge/LightGBM 表格基线 | 无神经网络时的可重建水平 |
| A1 | 只看个股自身特征的 MLP | 非线性本身是否有增量 |
| A2 | 线性截面注意力 | 跨股票共享是否有增量 |
| A3 | 单块单头浅层非线性注意力 | 非线性和共享结合后是否再有增量 |

A3 首期只能单块、单头。增加层数、注意力头、行业或关系稀疏掩码都必须创建新模型
版本和独立消融证据。

## 边界

- 模型只能输出带模型、特征、股票池和截止时间身份的 `PredictionBatch`；
- 股票池、排序和掩码必须点时版本化，不得为适配显存静默删股或重排；
- 必须记录截面规模、复杂度、峰值内存、训练时长、种子和 CPU/GPU 一致性；
- 超过资源预算时显式阻断或使用预先登记回退；
- 外部论文、代码仓库、Sharpe 或 SDF 结果不能替代本地 A 股证据；
- A0～A3 和 M0～M3 各自形成证据前，不得联合训练。

## 验收边界

1. A0～A3 使用同一 `FeatureSnapshot`、点时股票池、H20/H60 标签、切分、成本和执行
   约束。
2. A1 是区分“自身非线性”和“跨股票共享”的必需对照，不得跳过。
3. 原始多空或 SDF 权重不能直接成为 `PortfolioTarget` 或 `OrderPlan`。
4. 资源不足、股票池身份不一致或掩码缺失时失败关闭。
5. A3 未相对 A0/A1/A2 形成稳定成本后增量时保持挑战者。

## 授权边界

本需求只登记研究方向。它不授权模型实现、GPU 训练、策略晋级、Shadow、Paper、Live
或券商动作。
