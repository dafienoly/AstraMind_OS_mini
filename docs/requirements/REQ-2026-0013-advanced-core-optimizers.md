- 追踪：见[需求索引唯一追踪表](./README.md#唯一追踪表)

## 目标

在 REQ-2026-0007 的 O0 已形成稳定 A 股可执行证据后，检验方差之外的左尾和高阶矩
是否能改善周度核心组合。复杂求解器不是晋级理由，任何候选都必须复用同一个
`OptimizationProblem → OptimizationResult → PortfolioTarget → OrderPlan` 路径。

## 研究阶梯

| 层级 | 候选 | 进入条件 |
| --- | --- | --- |
| O0 | REQ-2026-0007 稳健基线 | 永久保留，允许现金 |
| O1 | 成本/换手约束 CVaR | 首个左尾风险对照 |
| O2 | 条件 MVSK | 高阶矩稳定性和状态切分预检通过后 |

三者共享偏度、超额峰度、下行波动、CVaR 1%/5%、最大回撤、最差市场分组、有效持仓
数、集中度和换手诊断。收益频率、窗口、样本数、缩尾/收缩/重采样、估计器和缺失规则
必须版本化。

## 失败关闭与复杂度边界

- O0/O1/O2 使用同一不可变输入、预测、持仓、成本、现金、流动性、单股/行业和整数手
  约束；
- 连续解通过 100 股修复后重新计算全部风险、费用、容量和换手；
- 样本不足、关键收益缺失或窗口/bootstrap 扰动不稳定时 O2 失败关闭，O0/O1 不受
  影响；
- 条件 O2 必须比较始终关闭、始终启用和预登记状态启用；
- 市场状态缺失、陈旧或置信不足时门控保持关闭，不由优化器创建第二套状态服务；
- 分钟级论文结果不能替代本项目日度/周度证据；
- 显式三/四阶共矩张量、盘中动态切换和自动求解器选择不在首期。

YAND 只登记为未来可能的求解后端。只有 O2 已有稳定本地增量，且普通求解器经可重复
基准证明为真实瓶颈，才可另开工作包评估；不得改变 O0/O1、公共契约或执行语义。

## 验收边界

1. 同一输入下 O0/O1/O2 发布同口径诊断和可追溯结果。
2. O1 记录 CVaR 置信水平、情景身份、持仓、换手和成本惩罚。
3. O2 在多个滚动样本外窗口和预登记状态中同时相对 O0/O1 比较。
4. 只在单一窗口、状态或成本前胜出时不得申请晋级。
5. 任何优化器都不能直接产生订单、绕过 O0 或创建平行组合系统。

## 授权边界

Live、MiniQMT 或真实订单。
