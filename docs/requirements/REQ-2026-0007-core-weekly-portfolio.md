## 目标

为 10 万元核心分仓建立按周评估、常态约五只股票的点时研究、模型比较和稳健组合
目标，并通过与短线相同的组合及 Shadow 契约运行。

## v1.1 研究假设与候选层级

待检验假设是：动量形成期内的交易日并非同等重要，少数承载个股特异性冲击、异常
量额、公司公告或市场跳跃的信息日，可能比普通交易日更能解释后续收益延续或反转。
该假设只是一项研究候选，不预设在 A 股成立。

“特征管理动量（CMM）启发”在本项目中表示：模型只调制一个仍可解释的历史收益聚合
结构，而不是以 CMM 名义直接使用无约束黑箱预测。首期候选按下列层级公平比较：

| 层级 | 候选 | 必须保留的作用 |
| --- | --- | --- |
| M0 | 标准等权动量 | 永久可重建的简单基线 |
| M1 | 规则式信息日加权 | 检验无需机器学习时，明确事件/冲击规则是否已经足够 |
| M2 | 受约束 CMM-lite | 由线性或表格模型产生个股状态调制量，再形成非负且和为 1 的日收益权重 |
| M3 | 受约束 CMM-FFN | 数据覆盖充分时，用 FFN 作为相同结构的复杂挑战者 |

M2/M3 的形成期、跳过窗口、权重温度或集中度规则、状态特征和输出身份必须版本化。
如果显式事件标签进入模型输入，而不只是用于事后解释或 M1 基线，必须形成独立特征
定义与消融证据，不能声称是对原论文结构的无变化复刻。

## v1.2 截面注意力研究假设与消融层级

待检验假设是：在同一决策时点，个股的后续收益排序可能不仅取决于自身特征，还取决于
其他股票的特征与状态；截面注意力可能从行业、规模、流动性或收益相关性等关系中提取
表格模型和只看自身特征的模型未捕获的信息。该方向来自
[NBER Working Paper 33351](https://www.nber.org/papers/w33351) 2026 年 6 月修订版，
仍是待在 A 股验证的研究假设。

[Bojupi/model-zoo](https://github.com/Bojupi/model-zoo) 只作为模型公式和原型结构的
非权威参考，不作为论文实证复现、项目依赖或本地收益证据。项目内候选统一输出
`PredictionBatch`，不得把论文或仓库的多空随机折现因子（SDF）权重直接变成
`PortfolioTarget`、`OrderPlan` 或交易动作。

首期按下列层级独立消融：

| 层级 | 候选 | 必须回答的问题 |
| --- | --- | --- |
| A0 | 正则线性或梯度提升表格基线 | 不使用神经网络时的可重建预测水平是多少 |
| A1 | 只看个股自身特征的 MLP | 非线性本身是否提供稳定增量 |
| A2 | 线性截面注意力 | 跨股票信息共享在可解释简化模型中是否提供增量 |
| A3 | 浅层非线性截面注意力 | 非线性与跨股票信息共享结合后是否进一步改善 |

A3 首个候选限制为单块、单头；加深、增加注意力头、使用行业或其他稀疏掩码，均创建
新的模型版本和独立消融证据。A0～A3 与 M0～M3 先分别检验；在两个方向各自获得稳定
样本外证据前，不构建 CMM 与截面注意力的联合模型。

## v1.3 高阶风险与组合优化研究阶梯

待检验假设是：对周度核心分仓，仅使用方差可能遗漏收益分布的不对称和左尾风险，但
样本偏度、峰度也可能因窗口、市场状态和少量极端观察而不稳定。阶段 5 先建立共享
诊断，再比较直接针对左尾的 CVaR，最后才允许 MVSK 作为条件挑战者；算法复杂度本身
不是晋级证据。

所有优化器复用同一 `OptimizationProblem → OptimizationResult` 接口、不可变输入、
成本模型、A 股执行约束和目标生成路径，不建立第二套组合系统：

| 层级 | 候选 | 定位与进入条件 |
| --- | --- | --- |
| O0 | 稳健近等权或风险感知权重 | 永久保留的首个简单基线，允许现金 |
| O1 | 成本与换手约束的 CVaR | 首个下行风险对照，不能替换 O0 或绕过整数手可行性 |
| O2 | 条件 MVSK | 只有高阶矩估计通过稳定性检查，并在预先登记的市场状态切分中比较 |

高阶风险诊断不是独立服务。O0～O2 都计算同一组组合级诊断：偏度、超额峰度、下行
波动、CVaR 1%/5%、最大回撤、最差市场收益分组、有效持仓数、集中度和换手。收益
频率、20/60 日目标对应的观察窗口、缩尾/收缩/重采样方法、缺失处理和估计器版本必须
冻结；分钟级论文结果不能直接替代本项目的日度/周度证据。

“条件”只表示离线研究中预先登记并可重建的市场状态分组或门控候选。首期必须同时
比较始终关闭、始终启用和条件启用，不先建设新的实时状态切换器。已有版本化市场状态
可作为上游上下文；状态缺失或置信度不足时明确标记不可用，不由优化器自行推断或静默
启用 MVSK。

YAND 只登记为可能的未来求解后端，不成为阶段 5 依赖、公共契约或独立优化系统。
只有 O2 已形成稳定的本地增量证据，且普通求解器被可重复基准证明为实际瓶颈时，才能
在新的工作包中评估 YAND；该评估不得改变 O0/O1、组合约束或目标/执行语义。

## 范围内

- 只为声明因子增加必要的点时财务和行业数据；
- 价值、质量、盈利、成长、动量、反转、低波和流动性因子目录；
- 标准动量、规则式信息日加权、CMM-lite 与 CMM-FFN 的同口径挑战者比较；
- 对历史日权重、集中度、主要贡献日及其公告/市场/可交易状态进行可重建诊断；
- 简单复合、线性和表格模型基线；
- 自身特征 MLP、线性截面注意力和浅层非线性截面注意力的独立消融；
- 截面注意力的股票池、掩码、计算资源、随机种子和输出身份诊断；
- 科技、周期、传统经济专家与全市场回退模型；
- 20/60 交易日预测和 Purged/Embargoed 滚动评价；
- 稳健近等权或风险感知优化基线；
- 所有优化器共享的偏度、超额峰度、下行波动、CVaR、回撤、尾部分组、集中度和换手
  诊断；
- 成本与换手约束的 CVaR 下行风险基线；
- 预先登记市场状态切分下的条件 MVSK 挑战者；
- 10 万元、约五只、允许现金的周度 `PortfolioTarget`；
- 通过公共执行语义进入本地 Shadow。

- 机械复制美股 153 个特征、月频多空组合或论文收益与回撤结论；
- 直接复制或依赖 `Bojupi/model-zoo` 的训练环境、CUDA 配置或模型权重；
- 将论文 SDF Sharpe、定价误差或仓库随机样例当作 A 股成本后组合证据；
- 首期把 CMM 与截面注意力合并为一个难以归因的模型；
- 未经独立证据直接增加注意力层数、头数或使用事后构造的行业/关系掩码；
- 直接替换现有短线动量/突破或已晋级的反转/量价策略版本；
- 使用公告前不可见的财务/事件标签，或用当前行业归属改写历史；
- 因 GPU 可用就自动晋级复杂模型；
- 因单次样本外收益、单一 Sharpe 或权重图看似合理就自动晋级复杂挑战者；
- 将样本偏度、峰度直接解释为稳定风险参数，或用分钟级论文结果替代本项目日度/周度
  证据；
- 为条件 MVSK 新建第二套市场状态服务、数据快照、组合契约或执行路径；
- 首期引入 YAND 依赖、显式三/四阶共矩张量、自动求解器切换或盘中动态切换；
- 强化学习直接控制账户；
- 自动增加核心分仓资金；
- MiniQMT、Paper、Live 或真实订单。

## 功能要求

1. 财务观察必须按公告和实际可用时间进行点时连接。
2. 因子定义、覆盖、缩尾、中性化、滞后和适用行业必须版本化。
3. M0～M3 必须使用同一个不可变 `DataSnapshot`、点时股票池、目标定义、成本和
   可交易性假设；缺少某候选必需特征时只能使用预先声明的回退或阻断。
4. M2/M3 的日权重必须非负且和为 1；系统必须记录权重集中度、贡献最大的交易日、
   状态调制量、特征定义和模型身份。
5. 个股冲击、异常量额、财报窗口、龙虎榜、市场/行业跳跃和涨跌停等“信息日”标签
   必须分别记录定义与 `available_at`；价格冲击事实与事后事件解释不得混为同一输入。
6. 行业样本不足时必须使用声明的回退模型或停止训练。
7. 模型比较必须记录训练数据、滚动窗口、Purged/Embargoed 规则、随机种子、代码、
   环境，以及 RankIC/单调性、成本后 Top-K 收益、换手、容量、回撤、左尾和权重集中度。
8. 研究组合必须按 A 股长仓、约五只、允许现金的真实目标评价，并纳入 T+1、100 股
   整数手、涨跌停、停牌、费用、滑点和流动性；不得用论文的美股多空结果替代。
9. 2023–2025 历史区间只有在候选定义冻结后才能作为封存回放，且继续披露其无法
   倒推证明“从未看过”；真正新增证据来自 2026 年及之后的本地 Shadow。
10. 优化问题必须包含当前持仓、现金、成本、流动性和风险约束。
11. 周度结果必须明确区分持有、调仓和不行动。
12. A0～A3 必须使用同一个不可变 `FeatureSnapshot`、点时股票池、20/60 日预测目标、
    训练/验证切分、执行约束和成本；A1 必须作为区分“自身特征非线性”与“跨股票信息
    共享”的必要对照。
13. A2/A3 只能输出带模型、特征、股票池和截止时间身份的预测分数与不确定性；
    `OptimizationProblem` 负责把预测转换为 A 股长仓目标，模型不得直接输出订单。
14. 截面股票池及任何流动性、行业或关系掩码必须按决策时点可见信息版本化；模型不得
    为适配显存而静默截断、重排或混入股票池外证券。
15. A2/A3 必须记录注意力候选规模、计算复杂度、峰值内存、训练时间、预先声明的随机
    种子集合，以及 CPU/GPU 一致性；超过资源预算时必须显式阻断或使用已登记回退。
16. A3 首期使用单块、单头并与 A0/A1/A2 分别比较；更深、多头或稀疏注意力不得覆盖
    既有 `StrategyVersion`，必须创建新版本并重新完成消融。
17. M0～M3 与 A0～A3 的独立证据形成前，训练流程必须拒绝以“CMM+AIPM”名义合并
    时间加权和截面注意力；联合候选需要新的范围与实施批准。
18. O0～O2 必须使用同一不可变输入、点时股票池、预测、当前持仓、成本、流动性、
    单股/行业限制、允许现金和 100 股整数手规则；不得因求解器不同改变问题口径。
19. 高阶风险诊断必须记录收益频率、窗口、样本数、缺失规则、缩尾/收缩/重采样方法、
    估计器版本和不确定性；样本不足、结果不稳定或关键输入缺失时 MVSK 失败关闭，
    O0/O1 保持可独立求解。
20. O1 必须包含 CVaR 置信水平、情景样本身份、当前持仓、预计换手和成本惩罚，并在
    连续权重和整数手修复后分别重算风险与成本。
21. O2 必须同时比较始终关闭、始终启用和条件启用；门控状态、阈值、置信度、回退及
    `MarketRegime` 身份预先版本化，状态未知时不得启用条件 MVSK。
22. O2 只有在 Purged/Embargoed 滚动样本外、多个市场窗口和 A 股成本后同时相对 O0
    与 O1 形成稳定增量时才可申请晋级；具体阈值在实施前另行批准。
23. 优化器专有诊断放在可重建的结果详情中，公共
    `OptimizationProblem`、`OptimizationResult`、`PortfolioTarget` 和
    `OrderPlan` 语义保持稳定；不得以 YAND 或 MVSK 名义建立平行契约。

## 验收标准

Given 一份公告日晚于评价时点的财务记录，When 形成因子面板，Then 该记录不可见。

Given 同一份不可变输入和相同模型身份，When 重建 M2/M3 日权重，Then 权重非负、
总和为 1，并产生相同的权重、诊断和内容身份。

Given 一个信息日标签在决策时点尚不可用，When 构建 M1 或包含显式事件输入的独立
挑战者，Then 该标签不可见，且系统不得用事件发生日或报告期末替代 `available_at`。

Given M0～M3 进入比较，When 形成滚动样本外证据，Then 四者使用相同快照、股票池、
预测目标、执行约束和成本，并分别展示按年份、行业和市场反弹/压力状态的稳定性。

Given 行业样本或覆盖不足，When 请求训练行业专家，Then 系统使用已声明回退或阻断，
不得伪造可用模型。

Given 相同预测、持仓和约束，When 重复求解基线优化问题，Then 产生相同
`OptimizationResult` 和 `PortfolioTarget` 身份。

Given 复杂模型没有稳定样本外提升，When 比较晋级证据，Then 表格基线保持有效，不因
模型复杂度自动替换。

Given CMM 挑战者在美股论文或本地研究回放中表现突出，When 尚无明确长线晋级决定，
Then 它仍是研究候选，不改变短线策略、`PortfolioTarget` 生产资格、Shadow、Paper、
Live 或券商权限。

Given A0～A3 进入比较，When 形成滚动样本外证据，Then 四者使用同一个
`FeatureSnapshot`、点时股票池、预测目标、切分、成本和执行约束，并分别披露多随机
种子离散度及按年份、行业和市场状态的稳定性。

Given A2/A3 产生预测，When 下游形成目标组合，Then 系统先发布可追溯的
`PredictionBatch`，再由同一 `OptimizationProblem` 应用长仓、现金、成本、风险和整数
手约束；原始多空 SDF 权重不能直接成为目标或订单。

Given 截面规模超过已登记计算预算，When 模型无法在声明资源内完成，Then 训练显式
阻断或采用已登记回退，不得静默删除证券、缩短历史或改变掩码。

Given A3 未能相对 A0、A1 和 A2 形成稳定成本后样本外提升，When 评估晋级，Then A3
保持挑战者，表格基线和较简单模型继续有效。

Given 论文或参考仓库报告高 Sharpe 或低定价误差，When 项目尚无自己的点时 A 股证据，
Then 这些外部结果只作为研究来源，不能替代本地验收、模型晋级或资金授权。

Given 请求联合 CMM 与截面注意力，When 两个方向尚未各自通过独立消融和晋级决定，
Then 联合训练被阻断，并提示需要新的候选版本与范围批准。

Given 同一不可变输入、预测、持仓和约束，When O0、O1 与 O2 进入比较，Then 三者使用
相同股票池、成本、流动性、现金、单股/行业限制和整数手规则，并发布同口径高阶风险
诊断。

Given 高阶矩窗口样本不足、bootstrap/窗口扰动结果不稳定或关键收益缺失，When 请求
条件 MVSK，Then O2 被明确阻断并记录原因，O0/O1 不受影响且系统不填零伪造收益。

Given 连续优化权重通过 100 股整数手修复，When 比较 CVaR 或 MVSK 增量，Then 系统
基于修复后的真实目标重新计算现金、换手、成本、偏度、峰度、CVaR 和回撤，不能只
展示连续解指标。

Given 市场状态不存在、陈旧或置信度不足，When 条件 MVSK 请求求解，Then 条件门控
保持关闭并显示状态证据缺口，不由优化器重新训练或创建第二套状态判断。

Given 条件 MVSK 只在单一窗口、单一状态或成本前胜出，When 评估晋级，Then O2 保持
挑战者，O0 与 CVaR 基线继续有效。

Given 普通求解器尚未成为可重复的性能瓶颈，When 请求引入 YAND，Then 阶段 5 拒绝
新增依赖或平行契约，并要求先提供 O2 本地增量证据和求解器基准。
