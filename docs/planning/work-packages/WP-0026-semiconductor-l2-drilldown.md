# WP-0026：申万二级行业“半导体”下钻

- 版本：1.0.0
- 状态：草案；同层基准与准确 UI 提案待决定，禁止实施
- 需求：REQ-2026-0008 v1.2.0、REQ-2026-0002 v1.2.0
- 阶段：2E、6C
- UI 提案：待建立并批准；不得从 `UI-PROP-0002 v0.2` 推导
- 日期：2026-07-28
- 券商授权：不适用；全程只读

## 目标

让用户从申万一级行业“电子”进入申万 2021 二级行业视角，能够找到并核验“半导体”
的身份、行情、相对位置和历史轨迹，同时保持一级与二级横截面严格分离。

首期是“电子 → 半导体”的可扩展试点，不把“半导体”伪装成第 32 个一级行业。

## 必须先决定

1. 二级轮动的比较基准：
   - 方案 A：只在“电子”所属二级行业内横截面比较；
   - 方案 B：在全部 `SW2021:L2` 行业中横截面比较。
2. 产品呈现：
   - 从一级轮动页选择“电子”后进入独立二级视图；
   - 或在右侧检查器中打开二级抽屉。
3. 首期只开放“电子”父行业，还是在数据完整后允许所有一级行业下钻。

这些选择会改变公式含义、覆盖规则和界面信息层级，不能由实施者默认决定。

## 规划范围

- 获取并版本化 `SW2021:L2` 分类身份及其父级 `L1`；
- 保存当前与退出成员区间，不用当前归属静默倒灌历史；
- 发布二级行业指数日线及覆盖报告；
- 明确验证“半导体”的提供方代码、父级“电子”、发布状态和可得日期范围；
- 新增独立的二级行业注册表与数据集版本，不修改 L1 数据集身份；
- 在确定的同层横截面内建立独立公式版本和 `MarketRotationSnapshot`；
- 下钻时显示层级面包屑、准确基准、覆盖数、截止日、公式版本和已知缺口；
- 返回一级视图后恢复原日期、行业、尾迹和筛选状态；
- 无二级数据、覆盖不足或层级身份不一致时明确阻断。

## 非目标

- 不把 L1 和 L2 节点放入同一个 z-score 横截面；
- 不把半导体加入 31 个一级行业列表；
- 不默认假设全部 134 个二级行业都有可发布指数日线；
- 不用个股拼接结果冒充提供方二级行业指数而不记录独立定义；
- 不在本工作包加入半导体个股推荐、策略、ETF 映射或交易动作；
- 不修改 `rotation-index-ew-v1.0.0` 的 L1 历史快照。

## 数据与点时边界

- 分类身份必须包含 `taxonomy=SW`、`taxonomy_version=SW2021`、`level=L2` 和父级代码；
- 成员关系使用 `[effective_from, effective_to)` 与实际可用时间；
- 2021 年以前按 SW2021 回溯的分类继续披露为回溯口径，不宣称当时已公开；
- 二级指数行情缺失时不使用 L1“电子”或当前成分等权收益静默替代；
- 每次请求只绑定一个不可变 `DataSnapshot`、一个层级和一个公式版本。

## 验收

1. Given 用户查看 31 个一级行业，When 搜索“半导体”，Then 界面解释它属于
   “电子 → 半导体”，而不是返回不存在的一级节点。
2. Given 用户从“电子”进入下钻，When 二级数据完整，Then 页面显示半导体及准确同层
   比较对象、基准、覆盖和公式版本。
3. Given L1 与 L2 输入同时存在，When 构建二级快照，Then 只有选定 L2 横截面参与
   标准化，L1 节点不进入计算。
4. Given 半导体指数日线或成员覆盖不足，When 请求下钻，Then 显示 `blocked` 和缺口，
   不用“电子”坐标或中心点替代。
5. Given 用户返回 L1，When 页面恢复，Then 原日期、选中“电子”、尾迹和筛选保持一致。
6. Given 任一二级页面正常显示，When 查看全部控件，Then 不出现个股推荐、ETF 目标、
   Paper、Live 或券商动作。
