# WP-0026：全 L1→L2→个股层级下钻

- 版本：1.2.0
- 状态：已完成
- 需求：REQ-2026-0008 v1.3.0、REQ-2026-0002 v1.3.0
- 阶段：2E、6C
- UI 提案：`UI-PROP-0002 v0.3`，已于 2026-07-28 批准
- 日期：2026-07-28
- 券商授权：不适用；全程只读

## 目标

让用户从 31 个 `SW2021:L1` 中任一行业进入其二级行业，再从任一 L2 进入指定日期的
有效成分股研究层。三个层级共享一个不可变 `DataSnapshot` 和 `as_of`，但分类注册表、
比较横截面、公式身份和覆盖分别记录。

“电子→半导体”是验收样例，不再是唯一开放入口。

## 已批准口径

1. 首期完整支持所有 L1，而不是先只开放电子。
2. L2 默认只在相同父 L1 内比较；用户可显式切换“全部 L2”。
3. L1 与 L2 不能进入同一个标准化横截面。
4. L2 成分股层同时提供相对轮动图、可排序列表和统一蜡烛图检查器。
5. 所有成员关系按 `as_of` 选择，不使用当前归属倒灌历史。
6. 层级下钻始终只读，不产生个股推荐、组合目标、订单或券商动作。

## 范围

- 发布完整 `SW2021:L2` 分类、L1 父级身份、当前与退出成员区间；
- 发布覆盖全部父 L1 的 L2 指数日线和覆盖报告；
- 为父级内 L2 和全部 L2 建立不同的基准/公式身份；
- 建立 L1、L2、股票三层可恢复 URL 和面包屑；
- 在 L2 层显示准确比较集合、覆盖、截止日、公式和已知缺口；
- 在股票层按历史有效成分构建同层相对轮动切片和研究排序；
- 复用统一 `PriceChartSlice` 展示所选股票日/周/月蜡烛图；
- 返回上层时恢复日期、父级、选中项、尾迹和筛选状态；
- 任一层级数据不完整时显示 `stale` 或 `blocked`，不静默换源。

## 非目标

- 不混合 L1、L2 或股票横截面；
- 不把半导体加入 31 个 L1 节点；
- 不用当前成分替代历史成员；
- 不用个股等权拼接结果冒充提供方 L2 指数；如需派生指数必须使用独立定义和身份；
- 不把研究排序描述为投资建议；
- 不增加 ETF 目标、策略晋级、Paper、Live 或下单控件。

## 允许修改

- `src/astramind_mini/data/` 下独立 L2 分类、成员、指数和股票切片数据产品
- `src/astramind_mini/market_regime/` 下层级轮动定义与构建入口
- `apps/web/src/market/` 中经 UI-PROP-0002 v0.3 批准的层级入口
- 追加式迁移、聚焦测试、合成 Fixture 和直接文档

## 数据与点时边界

- 分类身份包含 `taxonomy=SW`、`taxonomy_version=SW2021`、`level=L2` 和父级代码；
- 成员关系使用 `[effective_from, effective_to)` 与保守 `available_at`；
- 2021 年以前的 SW2021 分类回溯继续显式披露，不能声称当时已经公开；
- 每个请求只使用一个不可变 `DataSnapshot`、一个层级和一个比较集合；
- 父级内 L2 与全部 L2 使用不同的 `benchmark_definition_version`；
- 股票切片同时绑定 L2 成员版本、行情版本、`as_of` 和证据截止时间；
- 提供方缺少 L2 指数时失败关闭，不使用父 L1 或未版本化合成值替代。

## 验收

1. Given 任一完整 L1，When 用户点击“进入二级行业”，Then 展示其全部合格 L2、
   面包屑、父级内基准、覆盖和截止日。
2. Given 用户切换“全部 L2”，When 视图重建，Then 只改变 L2 比较集合和准确公式
   身份，不能混入 L1。
3. Given 用户进入“电子→半导体”，When 数据完整，Then 半导体身份、父级、同层对象
   和历史轨迹准确；它始终不出现在 L1 列表。
4. Given 用户从任一 L2 进入个股层，When 查看地图、列表和蜡烛图，Then三者使用
   同一快照、日期和当时有效成分。
5. Given 个别当日有效成分的 141 日面板不完整，When 请求个股层，Then保留完整成员
   列表和其可用 K 线，轮动只使用同快照内面板完整的成分并披露排除数量；若合格成分
   少于 3 个，Then显示 `blocked` 和准确缺口，不使用当前成分、中心点或父级坐标替代。
6. Given 用户返回上层，When 页面恢复，Then原日期、父级、选择、尾迹和筛选保持。
7. Given 任一层级正常显示，When 查看全部控件，Then不存在推荐、ETF 目标、Paper、
   Live 或券商动作。

## 预期证据

- 完整 L2 分类、父子身份和成员区间单元测试；
- 31 个 L1 均有明确 L2 覆盖或阻断原因的覆盖报告；
- 父级内/全部 L2 基准隔离及 L1/L2 混算负例；
- 历史成员点时正确和当前成员倒灌负例；
- L2→股票同快照、同日期集成测试；
- UI-PROP-0002 v0.3 批准后的桌面与窄屏浏览器工作流和截图；
- 提供方真实覆盖探测作为 Git 忽略的本地证据。

## 实施拆分要求

本工作包在实施前必须拆为至少两个互不混写高争用文件的子包：

- 数据与快照：完整 L2 注册表、成员、指数、股票切片和覆盖；
- 只读界面：层级导航、L2 轮动、股票列表与统一蜡烛图。

拆分不允许缩减“所有 L1”批准范围，也不授权联网探测或生产发布。

## 实施结果

- 数据发布命令支持 `INCLUDE_L2=true`，把 L1/L2 分类、历史成员和提供方指数日线发布
  到同一个不可变 `DataSnapshot`，并校验 31 个 L1 均有 L2 父级覆盖；
- 点时读取端口只接受准确快照身份和 `as_of`，父级内 L2、全部 L2 和成员股票使用
  不同基准身份；股票蜡烛图只读取相同快照中的日线；
- 个股轮动不会因一只新股拖垮整个 L2：当日有效成员全部保留在列表，141 日无新股、
  停牌等面板缺口的成员进入轮动横截面，其余成员继续提供可用 K 线并形成显式缺口；
- 页面提供 L1→L2→个股面包屑、同层轮动、排序列表和统一 K 线；
- 2026-07-28 获得独立联网授权后发布生产快照
  `snapshot:sha256:1764b7c3…e36d`：31 个 L1、134 个 L2 分类、15,886 条层级成员及
  682,462 条 L1/L2 指数日线；31 个父级均有 L2 覆盖；
- 提供方标记 124 个 L2 为已发布，全部具有指数日线；10 个未发布分类继续保留在
  分类证据中但不进入可比较节点，其中 9 个没有日线、1 个保留历史日线；
- 指数日线实际截止 2026-07-27，不把请求截止日 2026-07-28 冒充提供方已返回数据；
- 当前轮动指针已切换到绑定该数据快照的
  `rotation:sha256:431bc9e4…5f34`；电子父级真实验收返回 6 个已发布 L2 和 360 个
  轮动点；
- 31/31 个 L1 均可进入 L2：23 个父级可直接形成父级内轮动；公用事业、房地产、
  综合、通信、煤炭、石油石化、环保和美容护理只有 1–2 个已发布 L2，因此保留列表
  与继续下钻能力并显示 `sibling_cross_section_below_three`，不伪造横截面；切换
  “全部 L2”可比较 124 个已发布 L2；
- 生产发布中修正了 L1/L2 共用原始成员记录时的观察身份：保留同一原始证据的两个
  层级投影，同层同主键冲突继续失败关闭。
