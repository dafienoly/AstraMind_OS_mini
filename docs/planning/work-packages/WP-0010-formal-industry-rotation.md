# WP-0010：REQ-0002 正式行业资金轮动

- 版本：1.0.0
- 状态：已批准并完成
- 需求：REQ-2026-0002 v1.1.0
- 阶段：6C
- UI 提案：UI-PROP-0002 v0.1（已批准）
- 券商授权：无
- 日期：2026-07-28

## 目标

使用 WP-0009 的正式行业基础快照，冻结一版可解释、可重复的行业价格相对强弱公式，
发布不可变 `MarketRotationSnapshot`，并按已批准提案提供只读查询与本地回放页面。

## 非目标

- 不把价格相对强弱称为直接资金净流入或第三方专有 RRG；
- 不建设行业热力、生命周期、ETF、策略信号、组合目标或订单；
- 不连接 MiniQMT，不读取账户，不启用 Shadow、Paper 或 Live；
- 不增加第二套数据快照、任务系统或公式在线调参入口。

## 实施

1. 从一个准确 `DataSnapshot` 读取版本化行业分类、成员区间、行业指数日线与交易日历，
   DuckDB 只查询清单列出的精确 Parquet；
2. 冻结 `rotation-index-ew-v1.0.0`：行业指数对数收益相对 31 行业等权基准，20/60
   日 EMA 趋势、5 日动量、逐日中位数/MAD 标准化与 `100 ± 15` 有界坐标；
3. 31 行业指数面板要求 100% 完整，输出日每行业至少 3 个有效成分；缺失、零横截面
   方差或身份冲突均失败关闭；
4. 使用中心 `±0.25` 中性带和连续 2 日确认生成结构跃迁事件；
5. 内容寻址保存快照并原子更新当前指针；查询时重新验证内容身份；
6. `GET /api/market/industry-rotation` 只返回当前正式快照，缺失返回 404，损坏返回
   503；
7. `/market` 实现全部节点、选中尾迹、搜索、象限/跃迁筛选、日期拖动、播放/暂停、
   变速、尾迹长度、URL 恢复和方法检查器；逐帧不请求业务数据。


该命令只读取本地不可变数据。产物位于被 Git 忽略的 `var/research/market-rotation/`。

## 验收

1. 相同输入和公式重复运行产生相同逻辑内容与快照身份；
2. 缺失行业价格、成分覆盖不足、零方差、路径/清单身份冲突均失败关闭；
3. 输出恰为最近 60 个交易日，浏览器负载不超过 1 MiB；
4. 页面所有日期联动来自一次已加载快照，回放、筛选与选择不产生额外业务请求；
5. 桌面和窄屏保留截止日、公式、只读声明、失败状态和恢复动作；
6. 页面无目标、买卖、券商、Paper 或 Live 动作；
7. 聚焦测试、`make check`、`make e2e-smoke`、密钥检查和 `git diff --check` 通过。
