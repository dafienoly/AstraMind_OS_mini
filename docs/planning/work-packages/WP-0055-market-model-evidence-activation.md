# WP-0055：市场模型证据、挑战者比较与只读激活

- 版本：1.0.0
- 状态：已完成（生产候选与支持性证据尚未形成）
- 需求：REQ-2026-0002 v1.9.0、REQ-2026-0008 v2.0.0
- 阶段：6I
- UI 提案：不适用；本包不修改用户界面
- 分支/工作区：`codex/current-work-checkpoint-20260728`
- 券商授权：无

## 目标

实现支持性区块 bootstrap、三子区间、生命周期多指标、ETF 风险/成本诊断、不可变证据
存储和月度挑战者只读激活。所有失败都回到准确 v1，不产生策略晋级或交易动作。

## 非目标

- 不构建尚缺的生产特征矩阵或伪造生产模型；
- 不因代码通过而发布 `supported` 证据；
- 不修改 React/CSS/路由；
- 不创建组合、订单、Research Shadow、Paper、Live 或券商连接。

## 允许文件

- `src/astramind_mini/strategy_research/market_models/**`
- `scripts/run_market_model_monthly_activation.py`
- 对应公共导出、需求追踪与测试

## 证据规则

- 热力、相对轮动、行业排序使用 20 交易日圆形区块 bootstrap 的 90% 下界；
- 至少三个时间子区间中的两个方向为正，且挑战者均值不低于在位方法；
- 生命周期同时比较 Macro-F1、Brier、校准误差和阶段收益单调性；
- ETF 周度净收益优势使用 13 周区块，同时比较 CAGR、最大回撤、Calmar、换手、
  跟踪误差和成本，并要求 WP-0054 的数据门全部通过；
- 覆盖、风险、成本或换手任一恶化都不能更新只读指针；
- 证据、清单、激活历史只追加，当前指针可恢复；损坏或不兼容失败关闭。

## 验收

1. 区块 bootstrap 固定种子可复算，短样本阻断；
2. RankIC 下界不大于 0 或不足 2/3 子区间同向时失败；
3. 生命周期任一指标恶化时不能标记 `supported`；
4. ETF 数据门或风险/成本任一未通过时不能激活；
5. 合法支持证据只更新对应家族，损坏产物或身份冲突写入 v1 回退原因；
6. CLI 只接受不可变候选清单/证据，不调用提供方、账户或交易端口。

## 受保护边界

`ModelActivation` 只选择 Market Regime 的只读方法。它不等于策略 Promotion、
Renewal/Fallback，不授权 `PortfolioTarget`、`OrderPlan` 或券商动作。

## 实施结果

- 已实现固定种子的 20 交易日/13 周圆形区块 bootstrap、三子区间方向门、
  生命周期 Macro-F1/Brier/校准/单调性和 ETF 六项风险成本比较；
- 模型清单、证据、skops 产物与激活历史均为内容寻址、只追加存储；状态 API 每次
  校验 v2 的完整引用链，损坏时回退 v1；
- 月度 CLI 只接受已冻结候选，单家族同月只记录一次；ETF 缺少四个准确数据门中的
  任一个都不能激活；
- 正式快照就绪审计显示：热力/相对轮动可做开发研究，但历史行业广度成员并非当时
  已知，不能形成支持性证据；生命周期和行业排序同样受历史成员可用时点阻断；ETF
  受官方映射时点与 0/60 真实价差阻断；
- 未发布任何生产 v2、`supported` 证据或激活，状态 API 继续准确返回 v1；
- 45 个市场模型/ETF 聚焦测试、Ruff 和 Mypy 通过，券商动作始终为零。
