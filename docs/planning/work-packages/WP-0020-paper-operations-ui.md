# WP-0020：Paper 操作界面与正式验收

- 版本：1.0.0
- 状态：界面实现与自动化验收完成；真实券商运行态验收等待 WP-0019
- 需求：REQ-2026-0003 v1.2.0、REQ-2026-0010 v1.2.0
- 阶段：4E、7
- UI 提案：UI-PROP-0003/0006/0007/0008 v0.1，均于2026-07-28批准
- 日期：2026-07-28

## 目标

提供一个本地、脱敏、可刷新恢复的 Paper 操作工作面，让用户能区分目标、当前持仓、
待执行订单和券商事实，并只在确切限价、异常或恢复问题上投入注意力。

## 实现

- 五个一级入口保持不变；增加今日、组合、订单和系统准确路由；
- 全局决策状态带展示 `数据 → 风险 → 授权 → 订单` 和实际截止时间；
- 今日页使用决策时间线，不使用 KPI 拼盘；
- 组合页使用“当前 → 目标 → 待执行”持仓桥，并展示8%/10%/12%回撤动作；
- 订单页并排展示唯一金丝雀计划及执行/对账事实，明确 simulation、限价待批准、
  禁止重提和仅撤本单；
- 系统页按运行证据与恢复任务组织，提供只读投影刷新；
- 所有页面使用同一个 `/api/execution/paper-operations` 脱敏投影，页面没有提交或买入
  按钮，刷新不会触发 MiniQMT；
- Loading、API Error、授权阻断、断开、零意图和零券商事实均有真实状态。
