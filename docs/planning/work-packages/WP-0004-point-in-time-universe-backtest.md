# WP-0004：点时正确股票池与统一回测引擎

- 状态：已完成首个可执行基线
- 需求：REQ-2026-0001 v1.0.1
- 完成日期：2026-07-27
- UI：不适用

## 范围

股票池按当时可见的上市交易日数、ST/未知状态、双向可交易状态和 20 日成交额中位数
判断。事件覆盖通道只能豁免流动性筛选，不能绕过 ST、停牌、未知状态或执行约束。

统一日频回测引擎记录信号日、下一交易日计划执行、实际成交、拒绝和退出，包含：

- T+1 之后退出；
- 涨跌停/停牌状态、100 股整手；
- 佣金、最低佣金、印花税和滑点；
- 订单金额占成交额上限；
- 逐笔事件、交易、权益曲线与策略无关指标。

DuckDB 研究适配器只读取指定 `DataSnapshot` 清单列出的精确 Parquet，不接受
`latest` 或目录扫描。

## 验收与限制

测试证明未来信号不能同日成交、不可交易次日不静默重试、容量不足会拒绝。生产快照
小样本已经贯通，但它明确标记为 `bounded_plumbing_smoke_not_strategy_evidence`；
它不是开发期/封存期策略结论。全市场分批回放、Sortino/Calmar 与分市场状态报告仍是
后续研究运行工作。
