# WP-0002B-H3：历史名称/ST 与逐日可交易状态投影

- 状态：已完成
- 父工作包：WP-0002B
- 阶段：2B 可交易性事实切片
- UI 提案：不适用
- 数据源：旧 AstraMind 正式 Silver + H1/H2 精确版本数据集

## 目标

复用旧正式发布中的 `namechange`，建立历史名称与 ST/PT 风险区间；再用证券上市区间、
交易日历、日线、涨跌停价格和停复牌事件，生成从 2000 年起按年可恢复的逐日可交易
状态。全程本地执行，不联网、不读取账户。

## 冻结语义

`security_name_history` 保留提供方起止日、经下一名称起始日修正的有效结束日、公告日、
变更原因和 `normal/st/star_st/pt/high_risk`。4 个未闭合旧区间在下一名称生效前一日
闭合，原始结束日仍单独保留。

`daily_tradability` 的一行表示一只已上市证券的一个开市日，包含：

- 当日历史名称、风险状态与研究资格；
- 是否有日线，以及停复牌状态；
- 涨跌停价为可用、不可用或缺失；
- 是否封涨停/跌停，以及买卖两侧的可交易状态。

缺名称区间时使用 `unknown`，不以当前名称回填。无 Bar 只有在存在整日停牌 `S` 且
没有复牌 `R` 时才判为 `suspended`；其他情况保留为 `ambiguous_event` 或
`unknown_no_bar`。缺失或不可用的涨跌停价不会推断为可交易。投影的 `available_at`
统一为交易日 18:00，只能作为盘后约束证据。

覆盖事实：

- 名称历史覆盖 5,866 只证券，2,800 个区间属于 ST/PT/高风险；
- 964,864 个上市交易日缺少可证明的名称区间，保持 `unknown`；
- 17,119,507 行有日线；512,821 行有足够证据判为整日停牌；
- 74,696 行无 Bar 且没有停牌证据，9 行停复牌事件含糊；
- 2,101,366 行缺涨跌停价，其中主要为 2007 年以前；
- 302 行涨跌停价格明确不可用；
- 39,927 行封涨停，18,506 行封跌停。

17,707,033 个主键全部唯一；未知名称没有被填成 ST/非 ST，无 Bar 和不可用涨跌停价
没有被判为可交易。同一命令完成后的幂等重跑为 0.42 秒。

## 实现与恢复

- `make data-backfill-h3` 只要求旧数据根、旧版本和 H2 基础快照，不读取 Token；
- 名称区间先标准化为一个不可变 Parquet；
- 逐日状态按 27 个年度分区生成，每年完成后原子写入状态和文件哈希；
- 查询只使用基础清单列出的精确版本文件，不读取 `latest` 或扫描数据目录；
- 两个新数据集全部发布后才原子切换当前快照；
- H2 的“名称历史未提供”和“事件尚未投影”快照级缺口由新数据集取代，源数据清单
  自身的历史缺口仍保留。

## 非目标

- 不调用 Tushare `stock_st` 冒充全历史；该接口只能覆盖 2016 年以后；
- 不把投影视为盘前可得的因子或真实订单可执行证明；
- 不导入公司行为、行业历史或财务报表；
- 不连接 MiniQMT，不读取账户，不启用 Shadow、Paper 或 Live；
- 不实现 UI，不提交或推送 Git。
