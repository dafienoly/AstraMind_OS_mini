# WP-0002B：首个生产数据快照

- 状态：已完成
- 需求：REQ-2026-0001 v1.0.1
- 阶段：2B 的首个有界切片
- UI 提案：不适用
- 数据提供方：Tushare

## 目标

使用真实证券主表、SSE/SZSE 交易日历、最近一个保守完成交易日的全市场不复权日线
和复权因子，发布首个不可变、可查询、可审计的生产 `DataSnapshot`。

## 非目标

- 不在默认命令中执行 2000 年以来的日线与复权因子历史回填。
- 不接入估值、市值、换手、ST、停牌、涨跌停或公司行为历史。
- 不建立 MiniQMT 持续行情流，不读取账户，不下单或撤单。
- 不实现 UI、策略、回测、Shadow、Paper 或 Live。
- 不提交或推送 Git，不删除现有 `NUL` 文件。

## 发布规则

- 18:00（Asia/Shanghai）前运行时，最多使用前一自然日；18:00 后最多使用当日。
- 再从 SSE 与 SZSE 日历中选择不晚于该截止日的最近共同开市日。
- 证券主表分别读取上市、退市和暂停上市状态；交易日历从 1990 年起按十年分段读取。
- 日线和复权因子按所选交易日读取全市场数据；任一响应达到 6000 行时按疑似截断阻断。
- 提供方 `null` 保持为空值，不转换为文本；OHLC、正复权因子、主键和跨数据集覆盖均校验。
- 所有日线必须能关联证券主表和复权因子；只有复权因子而无当日 Bar 的证券作为已知缺口。
- 提供方没有逐条发布时间时，首摄入版本保守地以 `retrieved_at` 作为 `available_at`。

## 实现范围

- 新增四类冻结标准化观察：证券、交易日历、日线、复权因子。
- 新增可复用 Tushare HTTP 客户端、显式 DuckDB Schema 和 Parquet 编码器。
- 复用 WP-0002A 的原始只追加存储、内容寻址数据集、SQLite/WAL 台账和快照构建器。
- 新增 `make data-snapshot PROVIDER_ENV_FILE=...`；该命令显式联网，不属于 `make check`。
- 公共 `DataSnapshot` 与 `DatasetRef` Schema 保持兼容，其他薄腰契约没有变化。

当前生产快照：

| 数据集 | 日期范围 | 行数 |

验收确认：

- 四个当前指针均指向该快照声明的数据集版本；
- 四个数据集主键无重复，所有观察 `available_at <= snapshot.as_of`；
- 5,526 条日线均可关联证券主表和复权因子；
- 18 条复权因子没有对应当日 Bar，已记录为 `factor_rows_without_daily_bar`；
- 历史日线/复权因子、名称历史、停牌状态和 BSE 独立日历等范围明确留在 `known_gaps`；
- 第一次真实运行暴露并修复了提供方 `null` 日期边界；失败运行没有发布半成品。
