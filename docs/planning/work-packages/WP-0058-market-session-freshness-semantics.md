# WP-0058：交易时段感知的行情状态语义

- 版本：1.0.0
- 状态：已批准，待实施
- 需求：REQ-2026-0003 v1.8.0、REQ-2026-0004 v2.8.0
- 阶段：2C、6A、7
- UI 提案：复用现有准确提案；不改变布局
- 所有者：Data 状态契约，Market UI 只负责业务呈现

## 目标

把交易时段状态与传输健康状态分离，避免在午休、收盘后或非交易日把最新完成日数据
误报为“行情陈旧”。

## 非目标

- 不改变实时订阅、数据源路由或日线发布规则；
- 不新增页面或导航；
- 不连接账户、Paper/Live 或订单。

## 允许文件

- `src/astramind_mini/data/application/realtime_projection.py`
- `src/astramind_mini/data/contracts/realtime_projection.py`
- `apps/web/src/market-dashboard/RealtimePulse.tsx`
- 单一用途市场会话日历/状态模块
- 对应单元、集成和组件测试

## 验收

1. 连续竞价超过阈值无合法更新显示“行情更新延迟”。
2. 午间休市显示“午间休市 · 上午行情已保存”。
3. 收盘后完成日等于最近交易日显示“今日已收盘 · 日线数据最新”。
4. 非交易日显示“市场休市 · 最近交易日数据最新”。
5. 进程断开与完成日落后分别显示“实时连接中断”和“日线数据待更新”，两者不得混用。
6. 合成时钟覆盖开盘前、午休、收盘后、周末、断线和恢复。

## 高争用边界

不修改 Data 发布器、市场查询历史窗口、全局业务文案字典或共享样式；公共契约变更由
主控对话集成。
