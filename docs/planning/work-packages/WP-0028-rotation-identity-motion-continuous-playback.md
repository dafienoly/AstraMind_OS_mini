# WP-0028：行业视觉身份、运动状态与整段连续播放

- 版本：1.0.0
- 状态：已完成
- 需求：REQ-2026-0002 v1.3.0
- 阶段：6C
- UI 提案：`UI-PROP-0002 v0.3`，已于 2026-07-28 批准
- 日期：2026-07-28
- 券商授权：不适用；全程只读

## 目标

让高密度全轨迹仍能辨认行业身份和运动变化，并在保留逐日检查的同时提供不会在每日
边界停顿的整段连续播放。

## 前置

- WP-0027 已提供 raw_z、版本化显示变换、统一视觉帧和精确端点衔接；
- UI-PROP-0002 v0.3 已明确批准。

## 范围

- 31 个 L1 行业获得稳定、确定性、可测试的行业色；
- 组合框色标、节点、轨迹和检查器使用同一行业色；
- 选中/悬停轨迹提高饱和度和线宽，其余轨迹降低透明度但保留身份；
- 转强、转弱使用方向箭头或半环，加速使用双环/加粗最近轨迹，减速使用短虚线，
  并提供文字与图例；
- 状态只根据逻辑坐标计算：
  - 转强/转弱：相对动量穿越中性带并连续确认 2 日；
  - 加速：速度超过当前窗口 80% 分位且连续 2 日上升；
  - 减速：速度连续 2 日下降；
- 保留逐日 `0.5x/1x/2x`；
- 新增 10/20/40 秒整段播放，使用单一全局 playhead；
- 再次点击、`Esc`、清除控件和点击画布空白均可取消行业选择；
- 未选择时显示行业总览，URL 删除 `industry`，不自动重新选择；
- reduced motion 下连续播放退化为可控离散日期导航。

## 非目标

- 不把运动状态定义为投资信号；
- 不改变逻辑公式或 tanh 显示变换；
- 不加入 L2、股票、策略、ETF 目标或交易；
- 不让 31 条轨迹同时使用高饱和度；
- 不用市场红绿作为唯一状态编码。

## 验收

1. 同一行业跨日期、刷新和控件使用稳定色；颜色相近时仍能靠名称、选中和端点形状
   区分。
2. 合成穿越、加速和减速序列只产生准确标记；中性带抖动不产生转强/转弱。
3. 逐日模式维持既有检查能力；10/20/40 秒模式在误差容限内完成整个窗口。
4. 整段播放跨日期边界没有 playhead 清零、视觉停顿、轨迹断开或新增业务请求。
5. 四种取消操作都清除节点、检查器和 URL；刷新后不恢复已经取消的选择。
6. 全轨迹模式下选中行业保持主视觉，未选行业仍可通过稳定色追踪。
7. 键盘、焦点和 reduced motion 工作流完整；状态不只由颜色表达。
