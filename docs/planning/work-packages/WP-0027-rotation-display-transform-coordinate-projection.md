# WP-0027：轮动 raw_z、tanh 显示变换与统一坐标投影

- 版本：1.0.0
- 状态：已完成
- 需求：REQ-2026-0002 v1.3.0
- 阶段：6C
- UI 提案：`UI-PROP-0002 v0.3`，已于 2026-07-28 批准
- 日期：2026-07-28
- 券商授权：不适用；全程只读

## 目标

在不改变 `rotation-index-ew-v1.0.0` 逻辑坐标、象限和事件的前提下，保存硬截断前
`raw_z`，增加版本化 tanh 显示映射，并让轨迹末端与当前节点在任意画布尺寸下精确衔接。

## 范围

- `IndustryRotationPoint` 增加 `raw_z_trend`、`raw_z_momentum` 和
  `display_transform_version`；
- 冻结 `rotation-display-tanh-v1.0.0`：
  `display = 100 + 14 × tanh(raw_z / 2.5)`；
- 保持既有 `relative_trend/relative_momentum`、象限、事件和公式身份不变；
- 新旧快照显式区分；旧快照继续按原坐标显示，不静默重写；
- 节点、轨迹、安全边界和事件标记复用一个 `[0,100]²` 绘图投影；
- SVG 不再因固定宽高比产生留白偏移，线宽在非等比缩放下保持稳定；
- 一个行业每帧只生成一个视觉坐标对象，节点和尾迹末端共同引用；
- 公式抽屉同时解释逻辑公式、原始 z、显示映射和显示值非研究证据边界。

## 非目标

- 不修改正式收益、EMA、动量、稳健标准化、象限或事件规则；
- 不用动态坐标轴改变播放中的尺度；
- 不使用百分位排名替代强度；
- 不加入行业颜色、运动状态或整段播放；这些由 WP-0028 承接；
- 不接入 L2、个股、策略或交易。

## 兼容与失败关闭

- 新字段进入内容身份和 Schema 版本，生成物不得手改；
- 缺少 raw_z 的旧快照走准确旧映射并显示旧版本；
- 声明新显示版本但缺少 raw_z、参数不匹配或结果非有限数时阻断；
- 显示变换不能反写逻辑字段、事件或历史快照。

## 验收

1. 相同输入重建时逻辑坐标、象限和事件与 v1.0.0 完全一致，raw_z 和显示值确定。
2. 对任意 `raw_z`，tanh 显示保持符号与单调；极端值不全部落到 85/115。
3. 新旧快照都可读，且 UI 明确显示各自映射版本。
4. 桌面、窄屏、浏览器缩放、暂停、中间帧和跨日边界中，轨迹末端与节点圆心距离
   均不超过 2 像素。
5. 轨迹、节点、安全框和事件标记不得各自复制坐标公式。
6. 默认质量门不联网，测试使用合成极端值与尺寸 Fixture。

## 实施证据

- 后端保留 `raw_z_trend/raw_z_momentum`，新快照声明
  `rotation-display-tanh-v1.0.0`；既有逻辑坐标、象限和事件规则不变；
- 浏览器对新快照使用 `100 + 14 × tanh(raw_z / 2.5)`，旧快照继续使用原坐标；
- 节点和 SVG 尾迹共用百分比投影，`preserveAspectRatio=none` 且线宽不随非等比缩放；
- 单元测试覆盖确定性 raw_z、旧/新映射和统一投影。
