# WP-0037：行业与个股轮动常驻名称布局

- 状态：已完成
- 需求：REQ-2026-0002 v1.7.0
- 阶段：6C
- UI 提案：UI-PROP-0002 v0.7（`approved`）
- 日期：2026-07-28
- 券商授权：无；纯只读研究显示

## 目标

让行业和个股相对轮动图中的所有有效对象名称常驻可见，同时通过确定性的标签避让和
边缘标签轨保持节点坐标、象限与尾迹可读。

## 非目标

- 不改变轮动公式、节点坐标、筛选结果或快照；
- 不移动数据节点来制造视觉间距；
- 不重新引入所有对象的长尾迹；
- 不增加第三方图表运行时或发起业务请求。

## 拟实施范围

- 行业与个股图默认永久显示全部对象的标准简称；
- 标签先在节点周围八方向试放，再在同象限错层，最后进入左右边缘标签轨；
- 标签轨使用细引导线连接真实节点，选中标签保持深色置顶；
- 同一日期、视口和对象集合的布局必须确定，播放时不随机跳动；
- 筛选只淡化不匹配名称，不删除标签；
- 超过 16 个对象优先启用标签轨，超过 30 个提示展开聚焦但仍不隐藏名称；
- 移动端使用全宽画布和按象限分组的上下标签轨。

## 验收

1. 行业和个股图的每个有效节点都有一个常驻可读名称；
2. 任意两个标签边界不重叠，标签不越出可视画布；
3. 被移动的标签通过引导线准确连接原始节点，节点位置不因布局改变；
4. 相同输入重复布局得到相同结果，日期播放中没有随机抖动；
5. 选中、悬浮、筛选、缩放和平移后仍能识别全部名称；
6. 390px 没有页面级横向溢出，标准简称不被截断成无法识别的文字；
7. 布局计算只消费当前已加载数据，不产生业务请求。

## 实施结果

- 行业与个股共用的 `RotationChart` 永久渲染每个有效节点的标准名称；
- 确定性布局依次执行八方向试放、左右标签轨和网格兜底，标签轨绘制节点引导线；
- 选中和键盘聚焦标签保留运动状态与详细坐标，其他标签只显示名称以控制噪声；
- 密集模式下选中标签保持至少 28px 高度和固定行高，中文不会被内边距裁切；
- 原标签显隐开关已替换为“名称 · 全部常驻”状态，筛选继续只淡化对象；
- 60 对象、350×380 画布单元测试证明全部标签在界内、互不重叠且重复结果一致；
- 浏览器流程验证行业和个股标签数等于节点数、桌面及 390px DOM 标签无重叠，显示
  控制没有新增业务请求；
