# WP-0062：V2 生产特征矩阵、训练编排与预测发布

- 版本：1.0.0
- 状态：已批准规划；等待 WP-0057/WP-0059 与模型数据门
- 需求：REQ-2026-0008 v2.2.0
- 阶段：6I
- UI 提案：不适用；页面由已批准证据带和未来 UI-PROP-0013 承接
- 所有者：Strategy Research

## 目标

把现有五类训练内核接入生产特征矩阵、月度训练编排、内容寻址预测发布和准确状态
投影，先完成行业热力与相对轮动，再处理受点时成员和 ETF 真实证据阻断的模型。

## 实施顺序

1. 行业热力、相对轮动：生产历史矩阵、标签成熟切分、开发训练与未验证预测发布；
2. 生命周期、行业研究顺序：仅在点时行业归属证据满足后进入生产训练；
3. ETF：仅在官方基准、上市以来历史和至少 60 个交易日真实价差门满足后进入训练；
4. 证据不足时保持准确 V1，不用模拟预测填充。

## 状态

必须区分：`production_pipeline_unavailable`、`training_data_blocked`、
`trained_evidence_insufficient`、`validated_pending_activation`、`active`、
`artifact_incompatible`。页面业务文案由 WP-0060/0061 负责。

## 验收

1. 一次训练只读一个不可变、通过 WP-0057 完整性复核的 `DataSnapshot`。
2. 特征、标签、切分、依赖、模型和预测批次具有可复算身份。
3. 月度重复运行幂等；输入变化发布新版本，不覆盖历史预测。
4. 训练条件不满足时返回准确阻断状态，不生成模拟预测或激活。
5. 初始产物只读且不创建 `PortfolioTarget`、`OrderPlan`、Research Shadow、
   Paper/Live 或券商动作。

## 高争用边界

本包不得与 Data P0 恢复并行修改公共快照契约；只有 WP-0057 完成并由主控合并后才能
开始生产矩阵实现。
