# WP-0036：个股轮动聚焦镜片与可读性修订

- 状态：已完成
- 需求：REQ-2026-0002 v1.6.0
- 阶段：6C
- UI 提案：UI-PROP-0002 v0.6（`approved`）
- 日期：2026-07-28
- 券商授权：无；纯只读研究显示

## 目标

让三列股票证据工作台中的个股四象限在紧凑态可辨认，并提供不离开当前工作流的原位
聚焦态，用于阅读同层空间位置、运动方向和选中对象尾迹。

## 非目标

- 不改变相对轮动公式、坐标、象限、速度状态或快照；
- 不默认显示全部对象的名称和长尾迹；
- 不增加多级模态框、独立顶层页面、策略或交易动作；
- 不因缩放、悬浮、展开或收起发起业务请求。

## 拟实施范围

- 紧凑态只常驻选中对象标签，其余对象以端点表示；
- 悬浮/键盘聚焦显示临时标签与 X、Y、速度、运动状态；
- “展开聚焦”在当前工作台原位占满一行，K 线和证据保持挂载；
- 提供缩放、适配全部、中心 100、尾迹长度和标签密度控制；
- 同屏可读索引承担全部名称阅读并与图上选择双向同步；
- 对象超过 8 个时默认尾迹缩短为 5 个逻辑日。

## 验收

1. 350px 紧凑态没有常驻标签碰撞，选中对象、象限、轴和中心仍清楚；
2. 聚焦态在 1440px 下提供至少 680×520 的有效绘图区；
3. 缩放、平移、适配、标签和尾迹控制不改变逻辑坐标或请求数据；
4. 图、列表、K 线和证据使用同一选择，展开/收起不卸载 K 线；
5. 键盘和触屏均可选择对象，颜色不是唯一状态载体；
6. 390px 窄屏使用全宽聚焦态，关闭后回到原纵向顺序。

## 实施结果

- 紧凑态只绘制选中股票尾迹，并通过端点、悬浮和键盘焦点保留其他对象；
- 原位聚焦态提供缩放、拖拽平移、适配、中心复位、尾迹与标签控制，以及可读索引；
- 聚焦态只重排现有工作台，K 线与股票证据组件保持挂载，显示控制不发起业务请求；
- 1440px 聚焦绘图区通过浏览器断言达到至少 680×520，390px 没有页面级横向溢出；
- 组件、视口单元测试与完整可见浏览器流程均已通过；

  `var/evidence/wp-0036-stock-rotation-focus.png` 和
