# WP-0002B-H2：复用旧 Silver 的每日指标与交易约束

- 状态：已完成
- 父工作包：WP-0002B
- 阶段：2B 可交易性事实切片
- UI 提案：不适用
- 数据源：旧 AstraMind 正式 Silver + Tushare 最小缺口补充

## 目标

复用与 H1 相同的旧正式版本，导入 `daily_basic`、`stk_limit` 和 `suspend_d`，
形成每日估值/市值/换手、涨跌停价格与停复牌事件的不可变年度数据集。

## 实际来源与覆盖

旧版本 `a-share-daily-v1-20260724-4e1f5f6ae28d` 的状态为
`passed_for_formal_research`：

- `daily_basic`：6,434 个交易日、17,098,897 行，旧库只缺 2026-07-15；
- `stk_limit`：从 2007-01-04 起共 4,751 个交易日、15,615,348 行，只缺
  2026-07-15；
- `suspend_d`：591,840 条稀疏停复牌事件，缺 6 个日期分区。

本次只补 8 个“接口 × 日期”逻辑缺口。5 个 2000 年的 `suspend_d` 日期由
Tushare 确认为空，2026-07-15 补到 4 条停复牌事件。没有重新拉取已有历史。

## 标准化语义

- `daily_basic` 保留收盘价、两种换手率、量比、PE/PB/PS、股息率、总/流通/
  自由流通股本和总/流通市值；提供方定义为空的估值保持 `null`；
- 股本单位为万股，市值单位为万元，换手率和股息率单位为百分比；
- `price_limit` 保留昨收、涨停价、跌停价及 `limit_prices_usable`；
- `suspension_event` 同一证券同日可同时保留 `S`（停牌）和 `R`（复牌），主键包含
  事件类型与日内时段，不能粗暴按证券日期去重；
- `daily_basic` 和停复牌事件的 `available_at` 保守设为交易日 18:00；
- 涨跌停价格按 Tushare 公布的盘前更新时间设为交易日 08:40。

## 实现

- 沿用 H1 的年度流式 DuckDB 转换、原子状态文件、文件哈希和硬链接发布；
- 稀疏事件允许生成零行但有明确 Schema 的 Parquet，空响应仍保留原始证据；
- 完成年度按文件哈希恢复，不重算已封存年度；
- Tushare 兼容网关的 `stk_limit` 实际返回 7,692 行且忽略 `limit/offset`。该数量
  与相邻正式分区的 7,696/7,698 行连续，因此按真实网关行为验收，不套用公共文档
  的静态 5,800 行上限；
- 覆盖报告记录日线与每日指标/涨跌停的双向缺口，不因覆盖事实不一致而伪造补值；
- 当前指针只在三个数据集与新快照全部发布后原子切换。

`suspension_event_not_daily_state`；不能仅凭“当日没有事件”推断一定可交易。
