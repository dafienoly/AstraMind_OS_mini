# WP-0009：REQ-0008 行业数据基础

- 版本：1.0.0
- 状态：已批准并完成
- 需求：REQ-2026-0008 v1.1.0 的“行业数据基础 v1”
- 阶段：2E
- UI 提案：不适用；不新增或修改页面
- 券商授权：无
- 日期：2026-07-28

## 目标

把 SW2021 一级行业分类、历史成员区间和行业指数日线发布为可审计、可恢复、不可变的
数据集，并组合成一个新的生产 `DataSnapshot`，为后续生命周期研究提供准确输入。

## 非目标

- 不实现生命周期公式、行业热力、市场状态、ETF 或资金相对轮动；
- 不实现页面、策略、组合、Shadow、Paper 或 Live；
- 不连接 MiniQMT，不读取账户，不创建订单；
- 不把 SW2021 的提供方历史回溯分类声称为历史时点已知事实。

## 实施

1. `index_classify(level=L1, src=SW2021)` 固化实际 31 个一级行业；
2. 对每个一级行业分别请求 `index_member_all(is_new=Y/N)`，合并当前和退出成员，
   `effective_to` 采用右开区间语义；同一证券同一行业的提供方重叠区间保留并披露，
   跨行业重叠则阻断；
3. 对每个行业按不超过五年的窗口可恢复请求 `sw_daily`，范围为 2000-01-01 至基础
   快照的市场截止日；
4. 原始响应只追加保存，达到提供方行数上限即阻断；标准化层检查代码唯一、成员区间
   和 OHLC 关系；
5. 发布三个独立清单并从指定基础快照构建新快照；提供方未明确的成交量、成交额与
   市值单位保持 `provider_native_unverified`，不猜测换算。提供方存在极少数高低价与
   开收价差异小于 1bp 的舍入异常，原值保留并通过清单披露；超过 1bp 仍阻断。

## 命令

```text
make industry-data-foundation \
  PROVIDER_ENV_FILE=/mnt/e/work/AstraMind_OS/.env \
  BASE_SNAPSHOT_ID=<准确基础快照> \
  END_DATE=<基础快照市场截止日>
```

该命令显式联网，不属于 `make check`。Token 不复制、不输出；真实数据只进入忽略的
`var/`。

## 验收

1. 分类表恰有 31 个唯一 `SW2021:L1` 代码；
2. 成员关系包含当前与历史退出成员，区间无倒置，不用当前成员替代历史；
3. 行业日线只含正价格；OHLC 舍入容差不超过 1bp，空估值保持空；
4. 2000 年以来按提供方实际可得范围发布，清单披露每类数据实际首末日期；
5. 三个数据集和组合快照均由精确内容身份寻址，重复运行可恢复；
6. SW2021 历史回溯口径、成员发布日期缺失和提供方原生单位未核验均进入已知缺口；
7. 聚焦测试、`make check`、Schema 漂移、密钥检查和 `git diff --check` 通过。

## 受保护边界

本工作包不批准 REQ-2026-0008 其余草案范围。行业数据只能作为研究输入，不能直接
生成目标或订单；真实账户、券商连接与资金动作保持锁定。

## 实际结果

- 生产快照：
  `snapshot:sha256:607680ae4f1a626ae9166696fa72ea03d70846273cd28cd9e3a852e2442a6af0`；
- `industry_taxonomy` 31 行；
- `industry_membership` 7,943 行，实际生效日期范围 1984-05-09 至 2026-07-24；
- `industry_index_daily` 113,302 行，实际覆盖 2000-01-04 至 2026-07-24，
  覆盖 31 个一级行业；
- 249 个可恢复请求分区；幂等重跑 0.32 秒；
- 成员主键无重复、无倒置区间；58 组同证券同一行业的提供方旧/新区间重叠已披露，
  没有跨行业重叠；
- 日线无非正价格；发现的提供方 OHLC 舍入差异小于 1bp，原值保留并进入已知缺口。
