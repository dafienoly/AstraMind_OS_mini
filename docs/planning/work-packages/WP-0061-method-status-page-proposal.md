# WP-0061：系统“方法与状态”页面提案

- 版本：1.0.0
- 状态：提案已提交并通过批准前完整性验收；等待用户批准，页面实现未批准
- 需求：REQ-2026-0003 v1.8.0、REQ-2026-0008 v2.2.0
- 阶段：6I、7
- UI 提案：UI-PROP-0013 v0.1（`awaiting_user_approval`）
- 所有者：产品文档与 UI 设计

## 目标

提交“系统 → 方法与状态”二级页面的准确 UI-PROP-0013 v0.1，包括 SVG、桌面/窄屏
结构、状态和业务文案，供用户单独批准。

## 必须表达

- V1/V2 定义与五类模型目标；
- 数据可用、生产训练未接通、训练数据不足、证据不足、回退 V1、等待激活、已激活、
  制品损坏/版本不兼容；
- 数据日期、行情日期、市场时间和接收时间的区别；
- 常见数据缺口的业务解释；
- 只读边界和“模型激活不等于策略晋级或券商授权”。

## 非目标

- 不增加第六个一级导航；
- 不实现 React、CSS、路由或 API；
- 不批准 UI-PROP-0013；
- 不训练、激活模型或连接券商。

## 验收

提案位于 `docs/ui/proposals/0013-method-status/`，包含准确版本、状态
`awaiting_user_approval`、SVG、页面单一任务、可见数据、重要状态、主要动作和响应式
行为；用户批准前不得进入实现。
