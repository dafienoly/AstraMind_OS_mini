# 信息架构

- 状态：已批准基线
- 界面实现：市场行业轮动及 Paper 今日/组合/订单/系统工作面已实现；其余按提案状态

界面是一张个人交易工作台，不是管理后台。导航表达用户反复做的决策，而不是后端模块。

完整工作面、建议路由、提案映射和三条核心流程见[完整界面清单](./interface-inventory.md)。

## 全局框架

初期只保留五个一级入口：

| 入口 | 唯一任务 |
| --- | --- |
| 今日 | 当前发生了什么、系统计划什么、现在需要处理什么 |
| 市场 | 解释大盘、行业和 ETF 轮动环境 |
| 策略竞技场 | 比较短线逻辑、因子研究、冠军和挑战者 |
| 组合 | 解释持仓、收益归因、现金、目标和风险 |
| 系统 | 展示数据健康、作业、Shadow/MiniQMT、设置和常设授权 |

全局框架包含三个持续可见元素：

1. **一级导航**：始终只有五个入口。
2. **决策状态带**：紧凑显示 `数据 → 信号 → 风险 → 订单`、真实截止时间和阻断。
3. **需要你处理**：聚合超出授权、失败作业和未解决连接异常。

内部运行 ID、发布 ID 或审批流程不能成为一级导航。

## 今日

**唯一任务：** 一屏理解今日计划。

初期内容：

- 市场交易状态和数据新鲜度；
- 短线 5 万元分仓；
- 长线 10 万元分仓；
- 当前持仓与重要盈亏变化；
- 计划买卖与不行动原因；
- 风险/授权结果；
- 需要人工处理的异常。

“今日”不是通用大屏，只展示会改变今日决策的信息。研究详情通过侧边检查器或策略竞技场打开。

## 市场

市场页拥有“大盘 / 行业 / ETF 轮动”三个同级页签。

### 大盘

**唯一任务：** 回答“今天是什么样的 A 股市场？”

可见证据：

- 上证、深证、创业板、科创 50、沪深 300、中证 1000；
- 所选宽基指数的日/周/月蜡烛、成交量和均线；
- 上涨/下跌家数与新高/新低；
- 涨停、跌停、炸板和连板结构；
- 全市场成交额与近期分位；
- 大小盘、价值成长、防御周期的相对表现；
- 波动、回撤和流动性压力；
- 当前市场状态、置信度、截止时间和证据分歧；
- 风险、陈旧或缺失数据。

主要交互是切换观察周期或打开证据，不提供交易动作。

### 行业

**唯一任务：** 回答“资金参与正在向哪里增强、减弱或迁移？”

行业页内部有三个展示模式：

#### 行业热力

- 行业涨跌与相对强弱变化；
- 广度、成交额加速、换手和波动；
- 生命周期、持续时间、迁移方向和置信度；
- 点时正确覆盖允许时的估值与财务上下文；
- 领先/落后个股；
- 科技、周期和传统经济分组，但不隐藏底层行业分类。

选择行业后更新右侧检查器，不跳转到新的一级页面。

#### 生命周期结构

- 以可解释的行业结构坐标展示全部合格行业；
- 横轴、纵轴、气泡大小、颜色和描边都具有版本化业务含义；
- 行业数量来自当前分类注册表，不写死 56；
- 选择行业后进入同页“行业内研究排序”；
- 排序显示综合证据、情绪/事件、技术/量价、基本面、风险、反转和覆盖率；
- 选择股票后更新右侧蜡烛图检查器；
- 行业结构、研究排序和个股图使用同一个数据快照与 `as_of`；
- 页面保持研究观察，不直接生成订单。

#### 相对轮动

- 四象限相对趋势/相对动量画布；
- 当前行业节点与选中行业迁移尾迹；
- 时间轴播放、暂停、拖动、速度和尾迹长度；
- 行业搜索、象限筛选、仅选中、仅近期跃迁；
- 行业坐标、方向、覆盖率、结构跃迁、基准和公式版本；
- “研究观察，不是买卖信号”。

该模式受 [REQ-2026-0002](../requirements/REQ-2026-0002-market-relative-rotation-map.md) 和 [UI-PROP-0002](./proposals/0002-market-relative-rotation-map/proposal.md) 约束。

### ETF 轮动

**唯一任务：** 解释哪些可交易 ETF 方向通过当前轮动假设，以及为什么。

ETF 阶段完成前，这里显示真实的“尚未实现”状态。后续证据包括生命周期、相对强弱、ETF 流动性、跟踪、可交易性、组合重叠和调仓成本。

选择 ETF 候选后，同页显示日/周/月蜡烛、成交量、均线、时间窗口和流动性摘要；图表用于核验价格结构，不承担下单动作。

## 策略竞技场

**唯一任务：** 比较证据，并决定哪个版本可以产生目标。

内容：

- 不同短线策略家族和持有周期；
- 长线因子/模型实验；
- 冠军与挑战者；
- 开发、封存回放、当前 Shadow 与真实执行归因；
- 策略版本、数据快照、成本和失败场景；
- 手动晋级。
- 从候选、逐笔或目标列表打开统一个股蜡烛图检查器；
- 在封存回放中，只显示证据截止日及之前的 K 线与当时可见策略标记。

晋级通过一个对比检查器完成，不等于券商授权。

## 统一蜡烛图检查器

大盘指数、策略个股、行业内研究个股和 ETF 复用同一个交互模型：

- 标的身份、市场与实际截止时间；
- 日线 / 周线 / 月线；
- 蜡烛主图与独立成交量窗格；
- MA5 / MA20 等少量、可关闭的均线；
- 底部双端时间范围轴：左右手柄缩放窗口，拖动已选区间整体平移；
- 跨价格与成交量窗格的悬浮十字线；
- 逐 K 提示：交易日期、OHLC、涨跌额/幅、成交量、成交额和当前启用均线；
- 策略场景可叠加入场、退出、风险线和目标线，但必须标注来源版本；
- 数据陈旧、缺失、复权未知或窗口越过证据截止日时失败关闭。

图表只帮助理解价格事实与策略上下文，不把视觉形态直接转换成投资决定或订单。

## 组合

**唯一任务：** 解释资金和风险现在在哪里，以及目标有何不同。

内容：

- 短线、长线和账户总资金；
- 持仓、现金、目标权重和待执行计划；
- 收益与基准；
- 按策略、股票、行业和分仓归因；
- 流动性、集中度、因子和回撤风险；
- 8%/10%/12% 回撤状态与已记录动作；
- 本地与券商对账差异。

## 系统

**唯一任务：** 在不暴露基础设施噪声的前提下，使本地系统可操作。

内容：

- 数据新鲜度与覆盖率；
- 定时/手动作业进度；
- 快照和模型版本；
- Shadow 状态；
- 获得授权后的 MiniQMT 断开/Paper/Live 状态；
- 常设授权和异常规则；
- 本地设置、备份与恢复。

凭证、Token、账户 ID 和原始密钥永不显示。

## 渐进展开

- 第一层：结论、实际截止时间、置信度和下一动作。
- 第二层：可比较证据和关键驱动。
- 第三层：方法、数据身份、诊断和审计。

首屏不能同时堆满三层。

## 全局重要状态

每个入口显式设计：

- 首次使用/无数据；
- 布局稳定的加载；
- 新鲜且完整；
- 新鲜但不完整；
- 陈旧；
- 提供方不可用；
- 模型或策略不可用；
- Shadow 断开；
- 券商断开；
- 风险或授权阻断；
- 动作完成但对账中；
- 带恢复动作的严重错误。
