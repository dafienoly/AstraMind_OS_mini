# 视觉方向：安静的量化交易桌面

- 状态：已批准方向
- 实现状态：统一价格检查器、行业轮动和 Paper 操作工作面已部分实现

## 对象、用户与任务

产品是一张由一名技术型个人投资者每日使用的 A 股决策桌面。视觉任务是让高密度证据足够平静、可比较，同时让异常显眼，但不能像机构控制中心。

## 设计主张

界面像一本做工精良的市场笔记与交易记录簿融合：安静表面、严格对齐、清晰数字、从证据连续通向动作。

全局记忆点是**决策状态带**：

```text
数据 15:23 完整 ── 信号 4 个就绪 ── 风险 授权内 ── 订单 2 个计划
```

它承载真实工作流状态，不是装饰。

资金相对轮动页的局部记忆点是**迁移尾迹**：旧点逐渐淡出，当前点和方向始终清楚，让用户直观看见行业从哪里来、向哪里去。

## 色彩

核心色：

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 画布灰 | `#F2F4F3` | 应用背景 |
| 工作面白 | `#FFFFFF` | 主要工作区域 |
| 石墨黑 | `#172129` | 正文与强结构 |
| 雾灰 | `#68747C` | 次级文字与未激活状态 |
| 聚焦蓝 | `#2E5E84` | 选择、链接和中性进度 |
| 注意赭石 | `#B47A22` | 需要关注和证据不完整 |

市场语义色：

- 上涨：`#C34B43`；
- 下跌：`#238267`。

风险严重红必须比市场上涨红更深，并带标签或图标。未知状态使用灰或赭石，永不使用绿色。

相对轮动四象限使用低饱和底色，节点与尾迹使用行业稳定色；象限含义同时由标题、方向词和边界线表达，不能只靠颜色。

## 字体

- 中文正文与标签：本地打包 `Noto Sans SC`；
- 拉丁字符与金融数字：`IBM Plex Sans`，使用等宽数字；
- 代码、快照身份与紧凑诊断：`IBM Plex Mono`。

标题保持克制。层级来自字重、间距、分隔线和对齐，不依赖营销式巨型字体。

## 布局

- 以 1440px 桌面为主要设计宽度，兼容 1920×1080 和窄屏。
- 左侧窄导航，不使用嵌套永久侧栏。
- 顶部紧凑状态栏和决策状态带。
- 页面使用一个主分析画布和一个上下文检查器。
- 区域以留白和细线分隔，避免卡片套卡片。
- 表格列稳定、数字右对齐、表头吸顶、单位明确。
- 详情进入检查器/抽屉，日常导航不产生多级模态框。

## 图表

- K 线、成交量、进出场标记和价格叠加使用 Lightweight Charts。
- 广度、相对强弱、资金轮动和组合图只使用能表达关系的最小图形。
- 每张图必须有真实截止时间、图例、单位和空/陈旧状态。
- 装饰性小图不能替代可读数值。
- 红绿同时使用箭头、正负号和文字。
- 相对轮动节点必须可选择、可聚焦；尾迹的时间顺序通过透明度、点序或箭头表达。

### 蜡烛图契约

- 大盘、策略个股、行业内研究个股和 ETF 使用同一图表检查器，不各造一套交互。
- 主窗格显示蜡烛与少量均线，成交量使用独立下方窗格；价格与成交量时间范围同步。
- 图表底部固定提供双端时间范围轴：左右手柄分别调整起止边界，拖动已选区间整体平移；范围变化同步作用于蜡烛、成交量、均线和策略标记。
- 鼠标悬浮时显示跨窗格十字线与逐 K 浮层，至少包含交易日期、开高低收、涨跌额/幅、成交量、成交额和当前启用均线；空白或数据缺口不插值。
- 默认日线，提供周线和月线；短线策略可以额外聚焦最近 20/60/120 根，但不提供分钟级首发能力。
- 上涨使用市场红、下跌使用市场绿，同时以实体方向、正负号和文字表达，不只依赖颜色。
- 策略标记、目标线和风险线使用不同形状与图例，并显示策略版本和证据截止日。
- 封存回放的可视窗口不能越过证据 `as_of`；未来 K 线不能出现在历史决策画面。
- 双端范围轴只是可视窗口控制，不能改变数据快照、复权口径或证据截止时间，也不能通过继续拖动加载截止时间之后的数据。
- Loading、Empty、Stale、Blocked 和数据损坏状态保留图表布局，但不画演示蜡烛冒充真实数据。
- 实现阶段采用 Lightweight Charts v5 风格的 `CandlestickSeries` 与 `HistogramSeries` 双窗格；当前设计仓未安装依赖，届时必须先核验实际包版本和本地 typings，不能照抄旧版 API。

### 行业结构地图

- 横纵轴是经过版本化定义的行业参与结构，不使用没有口径的“综合分”坐标。
- 颜色表达生命周期阶段，气泡大小表达一个明确的规模或流动性变量，描边表达置信度。
- 标签碰撞时保留选中行业、极值行业和阶段迁移行业，其余通过右侧可读索引定位。
- 地图的视觉风险集中在一个地方：行业气泡形成“结构星图”；其余控件保持安静，避免做成炫技大屏。

## 动效

常规页面动效只用于：

- 决策状态带的一次状态过渡；
- 聚焦/选择反馈；
- 保留空间上下文的检查器变化。

相对轮动图是唯一允许持续播放的分析动效，但必须：

- 由用户主动播放，首次进入和刷新默认暂停；
- 提供暂停、变速、拖动和回到最新；
- 每帧只更新本地已加载数据；
- 暂停、切页或卸载后清理动画循环；
- 遵守 `prefers-reduced-motion`，改为离散日期切换。

禁止环境动画、跳动盈利数字和动态背景。

## 界面文案

- 使用用户语言：“今日计划”“需要你处理”“策略晋级”“数据未到齐”“相对轮动”。
- 控件直接说明结果：“晋级为短线冠军”“批准本次例外”“重建数据”“回到最新”。
- 主界面避免 artifact、candidate release、projection、run UUID 等内部名词。
- 空状态和错误状态说明缺少什么、为何重要、下一步能做什么。
- 相对轮动始终使用“研究观察”“结构跃迁”，不使用“买入”“卖出”“加仓”“减仓”。

## 明确避免

- 玻璃拟态、霓虹赛博、发光边框和渐变填充面板；
- 重复信息的巨型 KPI 卡；
- 每个标签都包圆角矩形；
- 通用 AI Dashboard 首屏；
- 没有可解释刻度的仪表盘；
- 超过两层的嵌套页签；
- 数据或券商状态未知时显示绿色健康；
- 为每个后端实体建立页面；
- 56×60 条尾迹默认全部高亮造成视觉噪声。
