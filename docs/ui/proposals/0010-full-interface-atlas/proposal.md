## 用途

本提案是索引稿，不是独立功能提案；其状态使用 `draft`，不能形成实施授权。它汇总 UI-PROP-0001 至 UI-PROP-0009 和 UI-PROP-0011，用于一次看清：

- 五个一级入口；
- 十七个重要工作面；
- 三条核心用户流程；
- 每个详细界面提案的批准状态。

v0.2 新增指数、策略个股和 ETF 的统一蜡烛图，以及行业生命周期结构地图和行业内研究排序；v0.1 保留为修订前索引。

总览图不能代替单个提案的批准。只有用户明确批准的提案版本，才可在后续已批准实施阶段作为界面基线。
