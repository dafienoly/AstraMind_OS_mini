# AstraMind OS Mini

一个面向个人投资者、本地优先的 A 股量化交易系统，目标是用尽可能短、清楚、可验证的路径，把研究结论推进到 Shadow，再在明确授权后接入 MiniQMT 实盘。

## 产品方向

- 先跑通个股实盘路径，再建设 ETF 轮动。
- 多种短线逻辑并行竞争，不预先永久指定唯一主策略。
- 本地 Shadow 不设固定 20 天等待期，允许基于封存样本与可见诊断手动晋级。
- 建设因子挖掘、分行业模型、周度长线组合和可替换优化器。
- 建设大盘、行业和资金相对轮动看板，再将行业生命周期用于 ETF 轮动。
- 通过常设授权把人工注意力集中到异常，而不是逐笔审批。
- 所有重要界面必须先提交版本化示意图，经用户明确同意后才能实施。
