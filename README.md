# AstraMind OS Mini

一个面向个人投资者、本地优先的 A 股量化交易系统，目标是用尽可能短、清楚、可验证的路径，把研究结论推进到 Shadow，再在明确授权后接入 MiniQMT 实盘。

## 当前状态

**历史数据、实时 L1、统一回测、短线候选、目标组合和本地 Shadow 基线已建立。** WP-0002B 已用
真实证券主表和双交易所日历发布首个快照；WP-0002B-H1 又复用旧 AstraMind 正式
Silver，并只补一个缺失交易日，形成覆盖 2000-01-04 至 2026-07-24 的日线与复权
因子历史快照。WP-0002B-H2 已进一步发布每日指标、涨跌停价格和停复牌事件；
WP-0002B-H3 已发布历史名称/ST 区间和 1770 万行逐日可交易状态；WP-0002B-H4
已发布公司行为、标准前/后复权兼容价和连续研究价格指数。WP-0002C 至 WP-0006
又建立了真实 MiniQMT L1 微批、统一价格 UI Lab、点时股票池与回测引擎、三类短线
候选，以及最多两只的战术目标与本地 Shadow 事件账本。封存期有效性证据、持续
Shadow、券商账户/交易连接和产品业务页面仍未完成。

用户已确认本机东莞证券 MiniQMT 可读取实盘/模拟盘账户，并可通过本地行情 RPC
接收 L1 全推。WP-0002C 已在明确授权下完成一次真实、短时、自动退订的 SH/SZ/BJ
全推采集；没有读取账户，也未获得账户查询、Paper、Live 或首单授权。

## 产品方向

- 先跑通个股实盘路径，再建设 ETF 轮动。
- 多种短线逻辑并行竞争，不预先永久指定唯一主策略。
- 本地 Shadow 不设固定 20 天等待期，允许基于封存样本与可见诊断手动晋级。
- 建设因子挖掘、分行业模型、周度长线组合和可替换优化器。
- 建设大盘、行业和资金相对轮动看板，再将行业生命周期用于 ETF 轮动。
- 通过常设授权把人工注意力集中到异常，而不是逐笔审批。
- 所有重要界面必须先提交版本化示意图，经用户明确同意后才能实施。
